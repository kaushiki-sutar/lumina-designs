# lumina-designs
A luxury fashion-inspired front-end website built with HTML and CSS.

## Features
- Luxury-inspired homepage
- Women's, Men's, and Kids' collections
- Elegant typography and animations
- Background video section
- The Maison page
- Creator page
- Responsive and modern design

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was created as an educational front-end web development project to practice website design, layout, and styling while creating a premium fashion brand experience.
